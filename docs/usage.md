# 使用说明与功能细节

本文详细说明 PhoneMIC 1.0.0 的交互、连接方式和使用边界。下载入口与截图见 [项目首页](../README.md)。

## 开始使用

1. 在安卓手机安装 [Android APK](https://github.com/23J1633/PhoneMIC/releases/download/v1.0.0/PhoneMIC-1.0.0-arm64.apk)，允许使用麦克风。
2. 在 Windows 10/11 x64 电脑双击 [Windows 接收端](https://github.com/23J1633/PhoneMIC/releases/download/v1.0.0/PhoneMIC-Desktop.exe)，程序直接在右下角托盘待机，不弹窗口或网页。
3. 手机与电脑连接同一局域网。打开手机右上角“设置 → 电脑”，点选搜到的电脑即可连接，无需验证码或手动验证。
4. 电脑上选中要输入的文本框，点击手机按钮开始说话，再点一次结束并输入文字。也可在设置中切换为按住说话、松开完成的实时输入方式。
5. 接收端会自动设为随 Windows 启动，之后手机打开即可重连。托盘使用与安卓端相同的白底橙色声环图标，右键可退出或重置手机连接。

找不到电脑时，可在手机中手动输入电脑的局域网 IP。客户端会验证首次连接时保存的完整证书指纹；IP 变化后，会通过局域网发现找回同一台电脑。

## 已实现

- 极简首页仅保留语音按键、右上角设置入口和宽幅细柱波形。识别后的文字无框显示在上方，完成后短暂展示再收起。
- 96 dp 语音按键带轻微渐变、高光、阴影和按压动效；按下立即短促震动，开始、结束和长按选择都有触感，独立于系统键盘触感开关。
- 使用最新的白底橙色声环矢量图标；连接、输入方式、语言、主题与历史统一收在设置中。
- 长按：识别过程中实时更新电脑中的文字，识别修订同步到电脑；松开后确认最终结果。
- 点击：说话时实时预览，停顿时确认语句，结束后统一输入。首段约 1 秒音频开始尝试预览，后续任务合并更新；结束优先复用最近已经识别的结果，仅补齐尚未识别的尾句，不等待整段录音重新识别。后台对文字和常用词英文大小写作轻量校正。
- 点击模式轻点结束只输入文字；长按结束键约 0.4 秒，按钮保持原位，上方出现“引导”“清空”“发送”三个气泡及随手指移动的引导线。滑向引导或发送后松开，在最终文字输入成功后执行该次快捷键；滑向清空则结束并丢弃本次录音和预览，不输入电脑、不触发快捷键，也不写入历史。移回中央松开保留录音，不执行动作。
- APK 内置 Qwen3-ASR-0.6B 的 INT8 本地模型、分词器和运行库，安装一个 APK 即可，首次打开自动初始化，无需另行下载或导入。自动识别中文、英文和同一句话里的中英混说，界面语言独立设置。采音和识别全部在手机进行，不上传声音、不使用远程推理、账号或 API Key。
- 中英文界面、浅色／深色／跟随系统主题。
- 最近 200 条本机加密文字历史，时间行右侧直接显示复制、发送到电脑、删除三个按钮。不保存录音。
- 两个快捷键独立设置，从屏幕按键表点选并组合 Ctrl、Alt、Shift、Win，支持 Page Up／Down、Home／End、Insert／Delete、F1–F24 和数字小键盘。按住模式保留预设的输入后动作，点击模式使用该次拖选；空录音、输入失败或重复回执不会再次触发快捷键。
- 设置中的“常用词”可保存最多 30 个、共 300 字的人名、软件名或术语，识别时作为千问的热词提示，不需要更换模型。
- 内置轻量人声检测和中英文 CAM++ 声纹模型。进入“设置 → 声纹”，使用平时的麦克风先正常说话 6 秒，再用平时的轻声或低声调说话 6 秒录入，检查多段声音的一致性并保存多个参考向量，成功后开启“仅识别我的声音”；可重新录入、关闭或删除。声纹在本机加密保存，不保存录音；匹配中心向量及多个参考后才接受片段，短语使用更严格的阈值。旧版单向量声纹继续兼容，重新录入可使用多参考匹配。
- 有线、USB 和蓝牙耳机麦克风自动优先使用。耳机媒体按键跟随点击／按住模式，分别支持两次点击开始结束、按下开始松开结束；点击模式收到按下即响应，播放／暂停指令分别执行开始／结束，重复指令不反向切换。模型就绪、回到应用或重新连接耳机时，使用轻柔的短提示音提前登记媒体按键；录音开始也有就绪提示。支持由耳机发起的后台录音，通知可结束录音。空闲时不打开麦克风，录音结束后释放音频焦点和蓝牙通话路由。
- 局域网自动发现、首次点选自动连接、TLS 加密、自动记住手机、断线重连；传输往返耗时可在连接详情查看。
- Windows 原生 Unicode 键盘事件，支持中文和英文，不占用剪贴板。发送回执、序号去重、未确认发送标记。
- 连接麦克风、处理、重连和输入电脑时显示简短状态；成功、未识别出文字、未连接电脑或发送失败均明确提示，文字保留在历史中。
- 蓝牙 HID 英文键盘模式，无需电脑接收端；在支持该功能的手机上可直接识别成蓝牙键盘。

录音最长 10 分钟。屏幕按键开始的录音在切后台时结束，耳机发起的录音可在已准备好的麦克风前台服务中继续。未连接电脑时仍可离线识别并保存在手机。临时断线保留录音，尚未发送的最终文字最多等待重连 8 秒；已经尝试发送但未获确认的文字不会自动重放，可在历史中核对后再次输入。

首页返回键会退到后台，前台待机服务和进程级缓存保留已经加载的模型；再次打开直接复用，不重新初始化。页面与服务的销毁不会主动卸载模型，只有后台进程真正结束后，下次打开才进行一次冷加载。待机时不录音，也不持续运行推理。

## 连接方式与实际边界

| 连接方式 | 中文 | 英文 | 电脑端 |
| --- | --- | --- | --- |
| 局域网 | 支持 | 支持 | 双击后台待机，手机首次点选后自动重连 |
| 蓝牙 HID | 不支持直接输入中文 | 支持 ASCII | 系统蓝牙配对，不用接收端 |

普通 HID 键盘报告不提供通用的 Unicode 文本输入，因此不将中文伪装为蓝牙键码。蓝牙模式需手机固件支持 HID Device，电脑使用美式英文键盘布局并关闭大写锁定。部分手机会在应用退到后台时注销 HID；保持 PhoneMIC 在前台使用。

蓝牙采用逐键输入，长篇录音结束后的集中输入会比局域网慢；优先使用局域网获得完整中英文和更低的传输延迟。

手机上的 `ms` 数值是局域网传输往返耗时，语音转文字还包含采音、模型推理和语句判断，不能保证零延迟。Qwen 在手机 CPU 本地运行，采用独立采音与识别线程、合并预览任务和分段识别，推理耗时取决于手机性能。噪声、口音与专有名词仍会影响准确率。

蓝牙麦克风需要耳机提供通话输入通道，建立通道可能需要额外时间。部分耳机固件只上报单击，或把长按留给系统助手；收到仅点击事件时会提示使用再按一次结束。系统将媒体键交给其他正在播放的应用时，需先回到 PhoneMIC。声纹对极短语音、不同麦克风音色或多人重叠讲话可能误判；建议使用平时使用的麦克风录入。声纹是说话人过滤，不能测出精确物理距离。

输入期间保持电脑目标输入框选中，不移动光标或使用电脑键盘。接收端检测到原生窗口或输入控件切换时会中止当前输入。管理员窗口可能要求接收端以同等权限运行。系统安全桌面和密码保护控件不保证接受注入。
